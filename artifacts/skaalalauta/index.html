Napauta otelaudan nuotteja peräkkäin (tai soita mikrofoniin / USB-äänilaitteeseen Kuuntelu-välilehdellä). Sovellus kertoo, mihin skaalaan ne sopivat parhaiten.

🏋️ Reenit & harjoitukset

📖 Opas

Aloitus

Istu ryhdikkäästi, kitara tukevasti. Vire: E–A–D–G–B–E (tai drop D / drop C metallissa). Käytä viremittaria tai Kuuntelu-tilaa.

Oktaavivalinta

Otelaudalla voit valita montako oktaavia skaalasta näytetään ja mistä nauhasta alue alkaa. Näin näet vain sen osan, jota juuri harjoittelet – ei koko kaulan täyteyttä.

Sormitukset

Sama root eri sormella → eri asema. 2 nuottia/kieli vs 3NPS. String skipping avaa uusia fraaseja. Harjoittele molempia suuntia. Monet reenit sisältävät vaihtoehtoisia sormituksia (esim. aloita 1. tai 2. sormella).

Bändihaku

Skaalat-välilehdellä voit hakea bändin nimellä (Slayer, Gojira, Sabbath, Mastodon…). Saat skaalat, joista kyseinen tyyli usein ammentaa.

USB-audio (M-Vave yms.)

Liitä laite → Asetukset → valitse äänilaite → säädä Gain. Jos signaali on heikko tai hyppii, nosta gainia ja soita yksi sävel kerrallaan. Chrome toimii yleensä parhaiten Androidilla.

Nopeus

Aloita hitaasti metronomin kanssa. Nosta 4–8 bpm kun on puhdasta. 3 notes-per-string + economy/alternate picking. Nauhoita itsesi.

⚙️ Asetukset

USB-vinkki (M-Vave Ann Blackbox ym.): Liitä USB-C → valitse laite listasta → Gain 2.5–4.0 → herkkyys matalammaksi jos kohinaa. Echo cancellation / noise suppression / AGC pois. Päivitä laitelista painamalla "Käynnistä mikrofoni" uudelleen. Chrome suositeltu.
