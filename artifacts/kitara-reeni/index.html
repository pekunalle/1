📖 Opas

Asento & vire

Istu ryhdikkäästi, kitara tukevasti. Vire: E–A–D–G–B–E (tai drop D / drop C metallissa). Käytä viremittaria tai Kuuntelu-tilaa.

Metalliriffit – nopeat vinkit

• Powerchordit (1 + 5) + palm mute
• Gallop-rytmi (1-a-ja) Iron Maiden -tyyliin
• Phrygian b2 riffin alussa = synkkä soundi
• Harmonic minor → dramaattinen V–i
• Tremolo-picking + phrygian = black/thrash

Nopeus

Aloita hitaasti metronomin kanssa. Nosta 4–8 bpm kun on puhdasta. 3 notes-per-string + economy/alternate picking. Nauhoita itsesi.

Sormitukset

Sama root eri sormella → eri asema. 2 nuottia/kieli vs 3NPS. String skipping avaa uusia fraaseja. Harjoittele molempia suuntia.

Skaalatunnistus

Soita 4–7 nuottia peräkkäin Tunnistus-välilehdellä. Mitä enemmän nuotteja, sitä tarkempi osuma. Root ei tarvitse olla ensimmäinen.
